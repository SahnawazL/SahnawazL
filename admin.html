▸ Required Environment Variables
1.Add ADMIN_SECRET to Vercel Environment Variables — this is the password you use to log in here.
2.Go to Firebase Console → Project Settings → Service Accounts → Generate new private key. Download the JSON file.
3.Add FIREBASE_SERVICE_ACCOUNT to Vercel Env Vars. Value = the entire contents of the JSON file (copy-paste as one line).
4.Go to Firebase Console → Storage → Rules. Make sure your bucket is your-project.appspot.com. Images will be stored under question-images/.
5.Deploy your updated ask.js to Vercel. Photo questions will now be automatically saved to Firebase Storage.
6.The KV_REST_API_URL and KV_REST_API_TOKEN are auto-added by Upstash when you link the KV database. These are already in your project (seen in your screenshot).

▸ Firebase Storage Rules
!Set Storage rules to block public reads (images are private — only viewable by admin via signed URLs):
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /question-images/{allPaths=**} {
      allow read: if false;   // Admin reads via service account
      allow write: if false;  // Server-side only
    }
  }
}
