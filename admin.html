Setup Guide
// ENVIRONMENT & DEPLOYMENT INSTRUCTIONS
▸ Required Environment Variables
1.Add ADMIN_SECRET — your admin panel password.
2.Firebase Console → Project Settings → Service Accounts → Generate new private key. Paste entire JSON as FIREBASE_SERVICE_ACCOUNT.
3.Get free Groq keys at console.groq.com → add as GROQ_KEY_1, GROQ_KEY_2, etc.
4.Get free Gemini keys at aistudio.google.com → add as GEMINI_KEY_1, GEMINI_KEY_2, etc.
5.Vercel Dashboard → Storage → Create KV Database → link to project → add KV_REST_API_URL and KV_REST_API_TOKEN.
▸ Files to Deploy on Vercel
→/api/ask.js — main AI backend (handles text, photo, quiz modes)
→/api/admin.js — admin API backend
→/admin.html — this admin panel (root of repo)
→/index.html — student-facing app (root of repo)
▸ Firebase Storage Rules
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /question-images/{allPaths=**} {
      allow read: if false;   // Admin reads via service account
      allow write: if false;  // Server-side only
    }
  }
}
